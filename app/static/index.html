SAHIAAYA · BILL VS BOX · PROMISE VS PROOF

Billed for 50.
Received only 48.

When a shopkeeper receives goods, the supplier's bill and the actual delivery don't always match. SahiAaya finds what's missing and remembers what the supplier still owes—even on the next delivery.

It helps small shops catch shortages, track promised replacements and avoid closing a claim without proof.

What is settled, what is still owed — across every delivery.

FalkorDB runs one max-flow over Delivery → Claim. Then it blocks each link and re-runs it: units that vanish are carried by that link in every valid allocation. Only those forced units are proposed; everything else becomes a supplier question.
